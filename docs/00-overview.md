# 00 · 仓库导览

> 本文档是 ai-pm-hub 仓库的导览，帮你 5 分钟内找到你需要的内容。

## 我是...

### ...产品经理，第一次接触本仓库

1. 先看 [README.md](../README.md) 了解 8 段全流程
2. 看 [docs/01-methodology.md](01-methodology.md) 了解方法论怎么沉淀出来的
3. 找一个跟你当前任务最近的段位，从 [skills/](../skills/) 对应子技能的 `SKILL.md` 开始读
4. 用 [docs/05-capability-map.md](05-capability-map.md) 看你正在做的事情属于哪个段位

### ...方法论贡献者，想加新内容

1. 读 [CONTRIBUTING.md](../CONTRIBUTING.md) 的 4 条硬规范
2. 读 [docs/02-anti-plagiarism.md](02-anti-plagiarism.md) 了解去行业化要求
3. 读 [docs/04-how-to-extend.md](04-how-to-extend.md) 看怎么加新段位
4. 提 Issue 讨论 → Fork → 新分支 → PR

### ...AI 工程师，要让 AI 编码代理读这个仓库

1. 仓库根目录的 `README.md` 是 AI 必读
2. `docs/images/capability-map.svg` 一图看清全貌
3. 每个 `skills/*/SKILL.md` 顶部是触发词 + 加载说明
4. 推荐把 `skills/` 整个软链接到你的 AI 工作环境

### ...Reviewer / 维护者

- 评审 checklist：[docs/03-framework-design.md](03-framework-design.md)
- 反抄袭检查清单：[docs/02-anti-plagiarism.md](02-anti-plagiarism.md)

## 5 分钟能力地图速览

```
市场洞察（5+1） → 用户与价值（5+1） → 验证与商业（8+1） → 产品设计（22+2）
                                                             ↓
                                          PRD（learn→write）  DESIGN.md  原型  UI 实现
                                          （1 风格档案）     （1+1 样例）  （2）   （1）
```

数字 = reference 文档数。括号内 `+N` 是样例数。完整数字：[docs/05-capability-map.md](05-capability-map.md)。
