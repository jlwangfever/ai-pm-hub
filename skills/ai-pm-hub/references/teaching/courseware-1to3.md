## 这份课件讲什么

不是某个技能的用法，是**「整条产品写作流水线长什么样」的总览**。三段一气走完：
**输入链**（后一份吃前一份的输出）→ **写作五步法**（怎么看 18 份文档）→ **WorkBuddy 六步法**（怎么用 AI 写文档）。

## 核心方法论（课件原话浓缩）

1. **写作五步法**：看目标 → 看全景 → 看输入链 → 看及格线 → 看怎么注入人工判断
2. **WorkBuddy 六步法**：把五步法教你看文档的视角，转成教 AI 写文档的执行步骤
3. **核心判断**：Agent 产的表「对但平庸」，你注入洞察才有杀伤力——所有可量化的格子 Agent 能填，**反直觉洞察只能人来**
4. **三段收敛物**：洞察段 1 句话 + 定义段 3 样东西 + 验证段 1 份排序表 = 一条完整决策链
5. **作业公式**：每份 = 素材包 + WorkBuddy + 及格线；写哪一段 @ 哪个库，别全塞一个库
