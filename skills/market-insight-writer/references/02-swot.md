# 02 SWOT 分析框架

## 回答什么问题

我们凭什么赢？内部强项弱项 × 外部机会威胁，交叉出什么打法？（定「打法」）

核心产出：从「四个象限」交叉出「具体策略」，并收敛到「做不做、往哪做」。

## 怎么分析

### 1. SWOT 四象限

- **S（Strengths 优势）**：内部 / 积极（能力壁垒、成本结构、闭环、技术、数据、团队）
- **W（Weaknesses 劣势）**：内部 / 消极（团队短板、能力缺口、品牌缺失、流程缺失）
- **O（Opportunities 机会）**：外部 / 积极（政策红利、窗口期、竞品盲区、需求刚需）
- **T（Threats 威胁）**：外部 / 消极（大平台入场、法规收紧、预算波动、替代方案）

**素材来源（关键）：** S/W 来自内部素材（自身能力、成本、团队、数据）；O/T 来自外部素材（政策、行业、竞品）。两者来源不同，勿混淆。

### 2. 每个因素带四重标注

- 编号（S1-Sn、W1-Wn、O1-On、T1-Tn）
- **量化证据**：数字、事实，而非形容词
- **置信度**：高 / 中 / 低
- **竞争含义**：这个因素对竞争意味着什么

### 3. TOWS 交叉策略四象限（核心，非只罗列四象限）

| 象限 | 组合 | 策略方向 | 要求 |
|------|------|---------|------|
| S×O | 优势 × 机会 | 进攻策略 | 每象限 ≥2 条 |
| S×T | 优势 × 威胁 | 防御策略 | 写清「组合 → 具体策略」 |
| W×O | 劣势 × 机会 | 改善策略 | 编号 SO-1…/ST-1…/WO-1…/WT-1… |
| W×T | 劣势 × 威胁 | 避险策略（危险区） | W×T 标危险等级 |

### 4. 反直觉洞察专节

提炼 1-3 条「反直觉」的判断（如：最大的竞品不是同类公司，而是用户的行为惯性；看似劣势的因素反而是壁垒）。

## 怎么写（结构）

1. **四象限表**：每个因素带编号 + 量化证据 + 置信度 + 竞争含义
2. **TOWS 交叉表**：四个象限的「组合 → 具体策略」
3. **反直觉洞察**：专节
4. **「所以呢」**：3 条行动，P0/P1/P2 + 时间窗

## 及格线

- ☑ S/W/O/T 四象限都有编号 + 量化证据
- ☑ 有 TOWS 交叉策略（不是只罗列四象限）
- ☑ 有反直觉洞察
- ☑ 结论是「所以呢」（能指导「做不做、往哪做」）
- ☑ 每个因素标了竞争含义

## 最易挂的坑

- **只罗列四象限不交叉**：SWOT 的价值在 TOWS 交叉，不是四个清单。
- **S/W 没料**：内部优劣势只写了泛泛形容词，缺量化证据（成本、数据、时间）。
- **每条没有量化证据**：形容词堆砌（"我们技术很强"），没有数字支撑。
- **「所以呢」把表格复述一遍**：结论没有升华成决策。
