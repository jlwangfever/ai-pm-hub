# 03 市场规模估算框架（TAM/SAM/SOM）

## 回答什么问题

市场够不够大？我们能切多大？（给投资人 / 给自己算钱）

核心产出：一个「带算法、可验证」的市场规模数字，以及「先吃哪块」的结论。

## 怎么分析

### 1. 三层金字塔（边界要清楚）

- **TAM（Total Addressable Market）**：总可寻址市场——理论上能服务的全部需求
- **SAM（Serviceable Available Market）**：可服务市场——TAM × 排除非目标（地理、客群、能力）
- **SOM（Serviceable Obtainable Market）**：可获得市场——SAM × 渗透率（保守假设）

每层必须写清边界和口径（谁算、谁不算）。

### 2. 估算方法交叉验证（核心）

- **自下而上（Bottom-Up）**：核心变量相乘（如「目标用户数 × 渗透率 × 客单价」），每个变量标来源与置信度
- **自上而下（Top-Down）**：从大市场层层切分（如「大市场 → 细分赛道 → 单品类」）
- **三角验证**：两种方法结果对照，取合理中间值作为推荐值

### 3. 敏感性分析（必做）

关键变量（如渗透率、选型率、客单价）变化时，TAM/SOM 怎么变。列出「基准 / 乐观 / 悲观」三档。

### 4. 细分与定价（提升可用性）

- **细分**：按地域 / 层级 / 客群拆解，找出「先吃哪块」
- **定价优化**：定价弹性分析（不同价位 × 预期渗透率 → 收入），分层定价设计

## 怎么写（结构）

1. **市场定义**：核心市场 + 定价模式 + 地理范围 + 排除项
2. **三层金字塔**：每个数字带算法（不能拍脑袋），如「TAM ≈ 目标用户数 × 客单价 ≈ X 亿/年」
3. **敏感性分析表**：关键变量三档对比
4. **细分**：地域 / 层级 / 客群 Top N
5. **「所以呢」**：先吃哪层、从哪起步

## 及格线

- ☑ 每个数字有算法（不是拍脑袋）
- ☑ 有敏感性分析
- ☑ TAM/SAM/SOM 三层边界清楚
- ☑ 数据来源可查（标置信度）
- ☑ 有「所以呢」（先吃哪块）

## 最易挂的坑

- **数字没有算法**：报一个数却没有计算过程。
- **口径混用**：分子分母口径不一致（如「用户数」和「付费人数」混用）。
- **没有敏感性**：只有一个静态数字，没说明关键变量变化的影响。
