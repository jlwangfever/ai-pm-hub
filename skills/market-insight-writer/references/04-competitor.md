# 04 竞品分析框架

## 回答什么问题

跟谁抢、抢得过吗？（定「对手」）

核心产出：竞品全景 + 赢/输判断 + 护城河，收敛到「先跟谁打、怎么打」。

## 怎么分析

### 1. 竞品三层次（关键）

- **直接竞品**：同类产品 / 同类公司
- **间接竞品**：功能有重叠但定位不同的产品
- **替代方案**：非同类产品但满足同一需求——**尤其要包含「现状 / 行为惯性」**（如手工、Excel、惰性、不上工具），这往往是最强竞品

> **关键点**：最强竞品往往不是同类公司，而是「现状 / 行为惯性」（用户目前用手工/旧方式凑合）。竞品分析必须包含它，并分析「用户为什么坚持用旧方式」。

### 2. 每个竞品五要素

- 定位 / 能力 / 价格 / 弱点 / 赢的场景

### 3. 结构化对比

- **功能对比矩阵**：多维（如入口、安全、分析、输出、行动、生态、商业层）
- **定价对比**：各竞品分层定价
- **竞品轨迹**：12-24 个月展望（对手接下来会怎么走）

### 4. 赢 / 输分析（vs 每个竞品）

- 赢的场景：我方赢的关键因素 + 概率
- 输的场景：我方输的关键因素 + 概率
- 赢的策略：针对性的打法

### 5. 护城河分析

- 我方的护城河（当前强度 / 可持续性 / 被侵蚀条件）
- 竞品的护城河（核心壁垒 / 被突破点）
- 护城河构建路线图（短期/中期/长期）

## 怎么写（结构）

1. **市场概述**：市场定义 + 竞争结构（三层次全景）
2. **竞品全景表**：每个竞品的定位 / 能力 / 价格 / 弱点
3. **对比矩阵**：核心维度对比（能力 / 价格 / 弱点）
4. **赢 / 输场景**：vs 每个竞品
5. **护城河表**：我方 vs 竞品
6. **「所以呢」**：先跟谁打、怎么打

## 及格线

- ☑ 竞品分三层次
- ☑ 有对比表（能力 / 价格 / 弱点）
- ☑ 含「现状 / 行为惯性」竞品（现状 = 最强竞品）
- ☑ 有赢 / 输场景
- ☑ 有护城河分析
- ☑ 结论指导「先打谁」

## 最易挂的坑

- **只写直接竞品**：漏了「现状 / 行为惯性」这个最大替代。
- **对比表没有「赢的场景」**：只列功能差异，没回答「什么情况下我方赢」。
- **护城河写成可复制的**：护城河必须「竞品短期内做不到 / 结构性不做」。
