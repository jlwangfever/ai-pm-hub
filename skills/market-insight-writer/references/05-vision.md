# 05 产品愿景框架

## 回答什么问题

我们要成为什么？一句有态度的选择。（定「魂」）

核心产出：一句有态度的愿景 + 验证机制 + 如何指导第一批决策。

## 怎么分析

### 1. 三个结构性矛盾（痛点起点）

先写清目标用户面临的 2-4 个结构性矛盾（长期存在、难以靠现有手段解决），愿景从这里生长出来。

### 2. 愿景陈述候选（5 个版本）

| 版本 | 定位 | 特点 |
|------|------|------|
| A 使命驱动型 | 对内动员 | 感性 + 具体，呼应使命 |
| B 场景直白型 | 对外/投资人 | 功能导向，带量化承诺 |
| C 对象导向型 | 用户传播 | 二分法让用户感到被尊重 |
| D 未来畅想型 | 社会/政策 | 从价值高度切入 |
| E 最精简型 | 首页 Hero | 短小对仗，一句话本质抽象 |

### 3. 推荐及理由

选定一个作为正式愿景，从五个维度评估：

- 感染力 / 可实现性 / 情感连接 / 区分度 / 可延展性

### 4. 价值观对齐 + 竞争格局定位

- 愿景映射到价值观（一条愿景对应一条价值观）
- 竞争定位：为什么我们能赢（呼应 04 竞品结论）

### 5. 愿景验证框架（5 维度，可被证伪）

| 维度 | 检验问题 |
|------|---------|
| 需求真实性 | 用户真的需要吗？ |
| 价值可感知性 | 用户能否快速感知差异？ |
| 技术可行性 | 技术上能否做到？ |
| 市场可扩展性 | 定位市场够大吗？ |
| 商业可持续性 | 用户愿意付费吗？ |

每个维度给「当前证据 → 目标证据」，并分阶段验证（需要 → 值得 → 可复制）。

### 6. 健康度仪表盘 + 沟通手册 + 演化路线图

- **健康度仪表盘**：关键指标标红黄绿线（健康/关注/干预）
- **沟通手册**：分受众叙事（投资人 / 一线用户 / 决策者 / 终端消费者），同一愿景对不同人说不同的话
- **演化路线图**：随产品阶段（种子期 → 推广期 → 规模化 → 品类扩展）愿景重点的演变

## 怎么写（结构）

1. **背景**：三个结构性矛盾 + 市场/政策背景
2. **愿景候选**（5 版本）+ 推荐理由
3. **一句话愿景** + 决策链（愿景 → 哪些决策）
4. **价值观对齐 + 竞争定位**
5. **验证框架**（5 维度 + 分阶段）
6. **「所以呢」**：愿景如何指导第一批决策

## 及格线

- ☑ 愿景是有态度的表达（能排除一些选择，如「不做 X、不排 Y」）
- ☑ 有决策链（愿景 → 哪些决策）
- ☑ 和 01-04 互相印证（政策 / 市场 / 竞品支撑）
- ☑ 有验证框架（能被打分 / 被证伪）

## 最易挂的坑

- **愿景写成「我们要做最好的 XX」**：换谁都成立，没有态度、不排除任何选择。
- **没有和 01-04 印证**：愿景悬空，和前面的市场/竞品结论脱节。
- **没有验证机制**：愿景变成口号，无法判断它是否成立。
