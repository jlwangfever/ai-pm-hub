提示词1：

先别写文档。请帮我做素材整理(这是写作前的准备,不要开始写):

1. 把【ChemAI-洞察】里政策/市场/竞品的素材,按 02-SWOT 需要的"外部机会 O / 外部威胁 T"两类归并,逐条列出"事实 + 来源(哪份素材、哪一条)"
2. 把【ChemAI-验证】里功能/成本/干系人/产品规格的素材,按"内部优势 S / 内部劣势 W"两类归并,同样逐条列来源
3. 去掉重复条目,标出互相矛盾的地方
4. 每条标依据可靠程度:外部可查证 / 多源归纳 / 待验证假设
5. 整理成结构化清单给我,我逐条核对后,再往下写



提示词2：

请基于【ChemAI-洞察】知识库(政策/市场/竞品)和【ChemAI-验证】知识库(功能脑暴草稿/成本账单与支出流水/干系人通讯录与备注/产品规划与评测草稿)的素材,参考《01-05洞察-结构骨架.md》中 02-SWOT 的格式,为 ChemAI(智辅化学)生成《02-SWOT 分析》文档初稿。
写作依据用刚才对话整理核对过的结构化清单,不要脱离素材另编。

要求:
1. 按 SWOT 四象限组织(S/W/O/T),每个因素带编号(如 S1、S2、S3……)
2. 每个因素必须有量化证据或具体依据(数据/事实/政策文号),禁止形容词堆砌
3. 每个因素标注"竞争含义"(为什么这条重要、对竞品意味着什么)
4. 输出 TOWS 交叉策略矩阵四象限(S×O 进攻 / S×T 防御 / W×O 改善 / W×T 避险),每象限至少 2 条,
   每条写清"优势+机会组合 → 具体策略"
5. 最后一段"所以呢":基于 SWOT+TOWS 给出 3 条最优先行动建议,标注优先级 P0/P1/P2
6. 找出一个"反直觉洞察"——最容易被忽略但影响最大的一个因素(提示方向:①最强竞品是不是老师自己的手工 Excel/行为惯性?②政策"鼓励→规范"的转换会不会比大平台入场更早关闭窗口?)
