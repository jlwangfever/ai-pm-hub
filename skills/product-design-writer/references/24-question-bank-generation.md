> 源文档：24-AI出题与题库管理系统设计.md

## 回答什么问题

题目从哪来、怎么组织、怎么进考试、历史资产怎么复用、相似题怎么检索、内容怎么导出？这是内容生产中枢，桥接「教学规划」与「练习落地」，为后续诊断/推荐提供结构化题目资产。

核心产出：出题工作台四 Tab 架构、三种出题模式、变体题生成逻辑、两级题库结构、考试生命周期状态机、真题库三层搜索、向量检索双层架构、知识图谱、试卷导出。

## 怎么设计（框架/步骤）

### 1. 出题工作台四 Tab 架构

单页工作台承载全部出题能力：Tab1 出题（AI生成/手动录入/扫描导入三子模式）、Tab2 题库管理、Tab3 历史真题库、Tab4 考试列表。明确每个 Tab 对应后端 API 与服务模块，共享设计系统与专业格式渲染（如公式 LaTeX/KaTeX）。

### 2. 三种出题模式（独立闭环）

- **AI 生成**：请求结构含知识点（必填）、难度（枚举）、题型、数量、变体源；分层 Prompt（System 角色定义 + 格式规范强约束 + User 有/无 RAG 上下文）；后处理 7 步（RAG检索→生成→JSON解析→安全审核→真题关联→陷阱提示→持久化）。
- **手动录入**：表单字段（内容/选项/答案/知识点/难度/解析），支持专业格式语法高亮。
- **扫描导入**：图片/PDF → 解析 → 文本切题 → 预览确认 → 批量入库；OCR 无法识别答案时由人工补填。

### 3. 变体题生成逻辑

选蓝本题 → 检索相似题 → 注入 RAG 上下文 → LLM 生成同知识点同难度变体。变体维度：数值变体、物质/对象替换、选项重组、题干重写、难度调整。响应携带 RAG 标记（is_from_rag / source_id / similarity / match_method）。

### 4. 两级题库结构

`QuestionSet（文件夹）→ QuestionSetItem（引用）→ Question（实体）` 树形管理，支持文件夹 CRUD、批量操作、系统预设保护。API 端点覆盖列表/创建/详情/删除/移除单题/批量导入。

### 5. 考试生命周期状态机

`Draft → AddingQuestions ⇄ Draft → Published → InProgress → Completed`，含删除终态。发布后行为写清：校验至少 1 题、置发布标志、统计人数、出现在学生端。题目关联支持双渠道（题库已有题 / 历史真题自动复制入库）。

### 6. 真题库三层搜索

`关键词匹配（结构化过滤，≥3 返回）→ 向量检索补充（similarity≥阈值）→ 联网搜索兜底`。仅在关键词极少时联网，结果标注「仅供参考」。前端树形浏览（地区→年份→试卷）+ 实时搜索。

### 7. 向量检索双层架构

- **每个知识标签一个向量**（非每题一个），使一题可从任意知识点维度被检索；嵌入文本融合知识点/题型/难度/来源/内容/答案。
- **两层检索**：第一层内存关键词初筛（重叠度+难度加权，取 Top-20 候选）→ 第二层向量精筛（ChromaDB 类，限定候选范围或全量）。ChromaDB 不可用时降级纯关键词。
- 索引构建智能判断（维度匹配/数量达标则跳过重建），保存题目时增量同步。

### 8. 知识图谱（扁平 category 结构）

知识点以 `名称→{category, description, related_kps, difficulty, exam_frequency}` 存储，related_kps 构成边。服务暴露搜索/关联/向量相似查询，支撑出题建议、弱项检测、变体推荐。

### 9. 试卷导出

Word（A4 排版、按题型分类、学生版/教师版含答案）与 HTML 报告（统计卡、高频错题表、鼓励区块、打印导出）。

## 文档结构

1. **系统定位与目标**：角色 + 指标 + 不在范围内
2. **出题工作台四 Tab**：架构图 + Tab 职责 + 三子模式
3. **变体题生成**：流程 + 参数 + 变体维度 + 响应标识
4. **题库结构**：两级模型 + API 端点
5. **考试生命周期**：状态机 + 各阶段 API + 双渠道关联
6. **真题库三层搜索** + **向量检索双层** + **知识图谱**
7. **试卷导出**：Word/HTML 规格

## 及格线

- ☑ 三种出题模式各自可独立完成出题闭环（AI/手动/扫描）
- ☑ 题库两级结构清晰（文件夹-引用-实体），API 覆盖 CRUD
- ☑ 考试有完整生命周期状态机（含草稿/发布/进行/完成/删除）+ 发布后行为
- ☑ 向量检索用「每知识标签一向量 + 关键词初筛+向量精筛双层」，且声明降级方案
- ☑ 真题检索三层递进（关键词→向量→联网兜底）；写清「不在范围内」

## 最易挂的坑

- **出题模式未闭环**：只设计 AI 生成，手动/扫描两条路径缺失，真实录入场景无人覆盖。
- **向量每题一个**：导致跨知识点检索召回低；应按知识标签拆分向量，多角度命中。
- **检索无降级**：ChromaDB 不可用即全盘失败；必须保留关键词兜底与维度不匹配自动重建。
- **考试状态机缺删除/回退**：只画发布成功，缺草稿调整与级联删除，数据清理无据。
