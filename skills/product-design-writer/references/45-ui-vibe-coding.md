# 45 UI 实现（Vibe Coding）写作框架

## 回答什么问题

原型（第 7 段）与 DESIGN.md（第 6 段）定稿之后，真正进入编码阶段：如何给 AI 下指令，让它**用组件库现成的组件**把界面做出来，而不是从零造轮子？本文档定义 Vibe Coding 五步法（问框架 → 选组件库 → 对组件名 → 写代码 → 要迭代）、两类场景的话术套路与框架-组件库对照表。

> **文档不孤立**：DESIGN.md（43 号）给视觉约束（色值/字体/组件规则），本框架给**组件选型约束**——「对组件名」这一步就是把 DESIGN.md 里的组件规则落到组件库的真实组件上。

## 怎么设计（框架/步骤）

**五步法（写界面之前必走）**：

1. **问框架**：先确定技术栈（React / Vue / 原生 HTML）——这是人的决定，不是 AI 猜的。
2. **选组件库**：自己项目自己挑（React→Ant Design / MUI / Arco；Vue→Element Plus / Naive UI；H5→Vant / Ant Design Mobile；小程序→TDesign / Vant Weapp）；公司项目团队已定，直接沿用。
3. **对组件名**：要什么效果，先对到库里现成的组件并**叫对名字**（导航栏→Menu、卡片→Card、详情弹窗→Modal、批量删除确认→MessageBox.confirm）；组件名不确定就反问 AI：「XX 交互，这个组件库里用哪个组件？」让它报名字。
4. **写代码**：把需求描述为「组件 + 布局 + 数据」，让 AI 用库里的组件拼装实现。
5. **要迭代**：一次只改一件事，一句话一改——「间距大点」「Modal 加个淡入」「删除按钮加 loading 防重复提交」。

**两类场景的话术区别**：

| | 场景一 · 自己做项目 | 场景二 · 公司项目 |
|---|---|---|
| 技术栈 | 自己选，先想好 React/Vue 再开口 | 团队定的，开场直接报现状（框架 + 组件库 + 页面场景） |
| 组件库 | 自己挑，报给 AI | 沿用团队的，不讨论选型 |
| 页面规范 | 自己说了算，边迭代边定 | **公司规范优先**：文案、提示方式直接说给 AI 听（如确认框标题、报错用统一 toast） |
| 共同点 | 都用库里现成组件、都对组件名、都靠迭代打磨 | 同左 |

**对话套路模板**（可直接复用）：

- 场景一开场：`我要用 [框架版本] 做一个 [产品类型]，组件库我选 [组件库]，可以吗？`→ 确认后再描述界面：`做一个 [页面]：[布局描述]，[组件效果 1]、[组件效果 2]……`
- 场景二开场：`我们的项目是 [框架] + [组件库]，[页面场景]。现在要给 [页面] 加 [功能]：[交互描述：操作 → 反馈 → 刷新/跳转]。`
- 组件名反问：`[某个交互]，[组件库] 里用哪个组件？`
- 规范注入：`[文案/提示] 按我们规范写：[具体规则]；[失败场景] 要用 [提示方式] 报错。`
- 状态细节迭代：`[按钮] 加 loading，防止重复提交。`

**与上游的衔接**：实现每个界面元素时，优先顺序是——组件库现成组件 > 组件库组件加定制样式 > 从零手写（仅组件库确实没有时）。DESIGN.md 的色值/字体约束在「组件 + 定制样式」时注入，不覆盖组件库默认主题能解决的部分。

## 文档结构

1. 场景判断：自己项目 / 公司项目（决定谁定技术栈）
2. 技术栈与组件库声明（一段话报清楚）
3. 界面需求描述（组件 + 布局 + 数据 + 交互反馈）
4. 组件名对齐表（效果 → 组件库真实组件名）
5. 迭代清单（每次一条：间距 / 动画 / 状态 / 规范）

## 及格线

- ☑ 开工前明确框架 + 组件库：自己定的说结论，团队定的报现状，绝不让 AI 猜技术栈
- ☑ 每个界面元素优先映射到组件库现成组件，并叫对真实组件名；不确定先反问再动手
- ☑ 公司场景已把规范（文案、提示方式、报错形式）显式告诉 AI
- ☑ 交互状态细节覆盖：loading 防重复提交、失败报错提示、空态
- ☑ 迭代一次只改一件事，每条改动可独立验证

## 最易挂的坑

- **不报技术栈就开工**：AI 按自己的习惯选框架和库，产出与项目环境不兼容，全部返工。
- **让 AI 从零造轮子**：不提组件库，AI 手写下拉、弹窗、日期选择器——样式不统一、无障碍缺失、维护成本高。
- **组件名想当然**：把「弹个确认框」直接当组件名，与库里的真实组件（如 MessageBox.confirm）对不上，生成的代码引用错误。
- **迭代一把梭**：一次提十个改动（间距 + 动画 + 文案 + 逻辑），改坏了不知道哪条引起，无法回退。
