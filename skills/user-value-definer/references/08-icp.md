# 08 理想客户画像（ICP）分析框架

## 回答什么问题

在所有可能用户里，该优先拿下哪类购买单位？谁值得重金投入、谁该礼貌拒绝？——为获客定"客"。
核心产出：一句话 ICP、定量评分模型与 Tier 分层、负向 ICP 清单、客户旅程六阶段、验证方法论。

## 怎么分析

### 1. 一句话 ICP + 选择/排除逻辑
- 一句话写清：哪个细分购买单位（地域/类型/规模/角色/特征）。
- 用表列「维度 × 选择逻辑 × 排除逻辑」，说明为什么是它而非别的。

### 2. 购买单位画像（Firmographics）
- **学校/企业/机构画像**：类型、所在地、规模、信息化/预算基础、压力/动力指标、现有工具使用。每项配"排除标准（NOT ICP）"与"判别方法"。
- **使用单位画像**：具体使用者角色（教龄/经验/痛点特征/期望），以及"组内结构"如何影响需求。

### 3. 决策流程画像
- 决策路径（谁发起→谁背书→谁审批→谁拍板）、关键影响者、关键决策者、决策周期、决策驱动因素、采购阻力、预算额度/门槛。
- 产品方应对：如何帮发起人"向上卖"、如何降低决策风险。

### 4. ICP 的 JTBD（引用 06/07 收敛到购买单位视角）
- 功能型/情感型/社会型 JTBD，各带成功标准（从购买单位而非个人使用者的角度重写）。

### 5. 痛点深度量化
- 表列：痛点 / 当前做法 / 痛点程度 / 定量影响 / 替代方案成本。量化到钱或时间。

### 6. 定量 ICP 评分模型（必带权重与公式）
- 选 6-10 个维度，每个给权重（Σ=100%）与评分标准（如"重点=10；普通=6；无=0"）。
- 公式：`ICP Score = Σ(维度得分 × 权重)`。
- 分级：≥8.5=Tier1；7.0-8.4=Tier2；5.0-6.9=Tier3；<5.0=NOT ICP。
- 给 2-3 个评分示例（理想/边缘/NOT），逐步算出总分，证明模型可用。

### 7. Tier 分层（1/2/3）
- 每层画像描述、典型特征、目标数量（时间窗）、服务策略（onboarding 频率/回访/案例培养）。

### 8. 负向 ICP（谁不该碰）
- 表列：负向 ICP 类型 / 原因 / 判别信号 / 若已接触怎么办。
- 5 题快速筛查清单：负向回答≥2→待评估；≥3→NOT ICP。

### 9. 客户旅程六阶段
- 意识→考虑→试用→采购→上线→倡导，每阶段：客户在想什么、我方触达/推进方式、关键指标、关键内容资产；标出 Aha Moment 设计。

### 10. ICP 验证方法论
- 假设表（H1-Hn：假设/验证方法/通过标准/数据来源/时间）。
- 访谈提纲（现状→体验→价值感知→改进，分层问题）。
- 验证数据 vs 感知数据交叉分析（如"说每周用"vs"实际周活"，差距≥30%即礼貌性好评）。

### 11. 线索评分模型（推广期用）
- 维度（ICP 匹配度/来源/紧迫度/决策权/时间窗/竞品使用情况）与分值，分级 Hot/Warm/Cold。

## 怎么写（结构）

1. **一句话 ICP + 选择/排除逻辑表**
2. **购买单位画像（Firmographics）+ 使用单位画像**
3. **决策流程画像**
4. **ICP 的 JTBD + 痛点量化**
5. **定量 ICP 评分模型**（维度权重表 + 公式 + 示例）
6. **Tier 分层（1/2/3）**
7. **负向 ICP + 5 题筛查**
8. **客户旅程六阶段 + Aha Moment**
9. **验证方法论 + 线索评分**
10. **「所以呢」**：Tier1 是谁、资源先砸哪、哪些线索直接弃

## 及格线

- ☑ 有一句话 ICP + 选择/排除逻辑
- ☑ 有定量评分模型：维度×权重 + 公式 + ≥2 个算分示例 + Tier 分级
- ☑ 有负向 ICP 清单 + 快速筛查问题
- ☑ 有客户旅程六阶段（含 Aha Moment）或验证方法论（二选一须有，建议都有）
- ☑ 痛点量化到钱/时间，决策流程清楚
- ☑ 结尾有「所以呢」

## 最易挂的坑

- **评分模型只列维度不算分**：没有权重、公式和示例，模型无法落地、无法复用。
- **只有正向没有负向 ICP**：不划清"谁不该碰"，种子期最容易在错误客户上浪费资源。
- **ICP 与 06 角色脱节**：ICP 应是 06 角色中"最值得优先"的购买单位，而非凭空另起炉灶。
