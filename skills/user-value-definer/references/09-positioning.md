# 09 定位策略分析框架

## 回答什么问题

在目标用户心智里，我们占据哪个空白位置？对每个受众该说什么？——为品牌定"位"。
核心产出：竞品定位地图、≥3 种定位创意（覆盖八类原型）、受众信息矩阵、可验伪的定位测试框架、演进路线图。

## 怎么分析

### 1. 竞品定位地图 + 感知双轴
- 表列竞品 / 当前定位 / 定位盲区，找出"所有竞品都没占的空白"。
- 画感知定位图：双轴（如"通用/统计 ↔ 单点深度诊断""用户自助 ↔ 专业主导"），把本产品与各竞品落点，标出空白象限。

### 2. 八种定位创意原型（至少产出 ≥3 种，覆盖不同类型）
1. **品类定义型**：创建新品类名（"AI 助教"），先发占位。
2. **场景切入型**：切入用户最高频的具体场景（"讲评课革命"）。
3. **认知差异型**：制造代差感，把竞品重新定义为"还不够好"。
4. **效率价值型**：功能性全流程/量化承诺（"10 分钟出报告"）。
5. **情感/价值观型**：温暖叙事，面向决策者/公众。
6. **B2B/学术型**：升级为"数据引擎/基础设施"，抬升绑定与付费。
7. **合规/信任型**：把安全/合规变成品牌核心资产。
8. **C 端/个人型**：面向终端个人的陪伴式定位。
- 每个定位写：定位陈述 + 战略理由 + 支撑信息 + 竞争优势 + 核心受众。

### 3. 定位选择原则
- 具体 > 抽象；用户语言 > 技术语言；避免与竞品正面比较（让客户自己比）；定位可叠加。
- 按受众/场景给"推荐定位"映射表（对老师第一句用哪个、对决策者用哪几个、对投资人用哪个、首页用哪个）。

### 4. 受众特定信息矩阵
- 表列：受众 / 核心诉求 / 首选定位 / 关键信息 / 避免信息。每条避免信息都是会触发防御的表述。

### 5. 品牌语调指南
- 语调原则表：如"像业内人士不像销售""具体>抽象""你视角非我们视角""诚实>炫技"，每条配好/差示例。

### 6. 定位测试框架（必须可验伪）
- **5 秒测试**：展示一句话定位 5 秒，问三题——"这是做什么的？/ 你记住了什么？/ 和别的有何不同？"通过标准：≥3/5 答对匹配。
- **深度访谈**：现有认知→读 3 个定位反应→比较选择→消极反应→让用户自提取一句话。
- **标语测试池**：列出候选标语对应各定位。

### 7. 定位演进路线图
- 四阶段（种子→推广→规模→成熟），每阶段用哪些定位、目标、触发条件（如"≥10 所学校付费 + ≥3 份 Case Study"才进阶）。

### 8. 定位风险与缓解 + 分场景执行手册 + 效果评估
- 风险表（如"被误读为替代人工"→始终强调辅助）。
- 分场景执行手册（教研会议/销售拜访/校领导汇报/家长会），每场景时间线×定位×动作。
- 效果评估：定位记忆率/差异化感知/试用转化率/漂移监控（每月抽查材料，漂移率<20%）。
- 跨文档一致性：在各对外文档指定主定位，避免漂移。

## 怎么写（结构）

1. **竞品定位地图 + 感知双轴图**（标空白象限）
2. **八种定位创意**（至少 ≥3 种，逐一定位陈述+理由+支撑+优势+受众）
3. **定位选择原则 + 受众信息矩阵 + 品牌语调**
4. **定位测试框架**（5 秒法 + 访谈 + 标语池，含通过标准）
5. **演进路线图**（四阶段 + 触发条件）
6. **风险/执行手册/效果评估/跨文档一致性**（按需要选写）
7. **「所以呢」**：主定位选哪个、对 ICP 说什么、怎么验伪

## 及格线

- ☑ 有竞品定位地图 + 感知双轴，并指出空白象限
- ☑ 产出 ≥3 种定位创意，且覆盖八类原型中不同类型（非同一类反复写）
- ☑ 有受众信息矩阵（谁/诉求/首选定位/避免信息）
- ☑ 有定位测试框架且含可量化通过标准（5 秒测试 ≥3/5）
- ☑ 定位与 06-08 的角色、价值、ICP 互相印证
- ☑ 结尾有「所以呢」

## 最易挂的坑

- **定位写成了功能清单**：定位是心智位，不是"我们有哪些功能"；要能一句话说清"你是什么、和别人有何不同"。
- **没有验伪测试**：写完后不做 5 秒测试，用户根本记不住/说不对，定位等于无效。
- **八种原型只写一种类型**：反复写"效率型"会丢掉的"情感/合规/C端"往往才是差异化突破口。
