# 用户与价值定义分析框架总览

> 为五份用户与价值定义文档补齐「数据从哪来 → 怎么分析 → 怎么写 + 及格线」。
> 本文件是总览，每份文档的详细框架见同目录下 06-10 各文件。

## 一、素材 → 文档对应（写哪份，喂哪类素材）

| 素材类型 | 喂给哪份文档 |
|---------|------------|
| 用户/角色访谈记录、使用行为数据、动机地图、Onboarding 反馈 | 06-用户画像 |
| 各角色当前流程耗时、替代方案、改善前后数据、切换阻力 | 07-价值主张 |
| 购买单位信息（规模/预算/决策流程）、客户案例、线索数据 | 08-ICP |
| 竞品定位、心智感知调研、受众分层信息、品牌语调偏好 | 09-定位策略 |
| 目标地域/城市数据、细分市场候选、竞争真空度、资源预算 | 10-滩头阵地 |
| 上游「市场洞察」结论（市场规模、竞品、宏观环境） | 06-10 全程引用 |

## 二、一句话话术（五份文档 3 秒定位）

| 文档 | 一句话 |
|------|--------|
| 06 用户画像 | 谁是核心用户？功能/情感/社会三类 JTBD，外加一个反直觉洞察 |
| 07 价值主张 | 对每个角色：Before→After，且价值可量化、切换成本高 |
| 08 ICP | 谁最该优先？一句话 ICP + 定量评分 + Tier 分层 + 负向清单 |
| 09 定位 | 占据哪个空白心智？八种定位原型选、受众信息矩阵、可验伪 |
| 10 滩头 | 第一战打哪？四标准评估 + 具体到城市的评分 + Go/No-Go |

## 三、输入链（06 → 07 → 08 → 09 → 10）

- 06 给角色和 JTBD；07 把 JTBD 变成可量化的价值与切换成本；08 从角色中锁定最该优先的购买单位并量化评分；09 决定对这些单位说什么、占什么心智位；10 在 ICP 内选出第一个该攻下的细分市场。
- 上游吃第 1 阶段「市场洞察」结论，下游喂第 3 阶段「验证与商业模式」与第 5 阶段 PRD。
- 后一份吃前一份的输出——这是多份文档能快速、自洽产出的真正原因。

## 四、统一写作主线

```
素材进库（定输入）→ 套框架 → 产核心表 → 写"所以呢" → 过及格线
```

每份文档都必须：有结构化框架 → 有 1-3 张核心表 → 有价值量化（07）/评分模型（08）/评估表（10）→ 有「所以呢」结论 → 过及格线自检。

## 五、及格线总表

| 文档 | 及格线（每项都须满足） |
|------|---------------------|
| 06 用户画像 | 每个核心角色有基本信息 + 三类 JTBD + 三大痛点 + 三大期望收益 + 1 个反直觉洞察 + 产品适配评估；次要角色说明；有行为/Onboarding 佐证 |
| 07 价值主张 | 每个角色六段式（Who-Why-B-A-H-A）；有蓝海价值曲线/对比表；Job Map 八步；价值量化（改善前→后带算法）；切换成本分析 |
| 08 ICP | 一句话 ICP + Firmographics + 决策流程 + JTBD + 痛点量化；定量评分模型（权重+公式+Tier 分层）；负向 ICP 清单；客户旅程六阶段；验证方法论 |
| 09 定位 | 竞品定位地图 + 感知双轴；≥3 种定位创意（覆盖八类原型）；定位选择原则；受众信息矩阵；定位测试框架（可验伪）；演进路线图 |
| 10 滩头 | 候选滩头清单；四标准评估表；推荐滩头定义（具体到地域/人群）；城市/细分评分模型；12 周计划；成功指标 + Go/No-Go 退出条件；相邻扩张序列 |

## 六、统一红线（所有文档通用）

1. **量化真实性**：价值改善、ICP 评分、滩头规模的数字必须带算法与来源。无法核实的标注「假设/待验证」，禁止编造。
2. **JTBD 三类齐全**：功能/情感/社会三型，缺一不可；反直觉洞察必须存在。
3. **结尾必有「所以呢」**：先服务谁、说什么、打哪块、现在做不做——没有决策含义的文档是半成品。
4. **去行业化**：框架层用通用表述；行业角色、竞品、术语、数字按新领域重新生成，禁止照搬样例。
