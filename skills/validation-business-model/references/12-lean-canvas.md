> 源文档：12-精益画布.md

## 回答什么问题

一门生意的九格骨架是否成立？问题是否真实、方案是否对症、价值主张是否独特、壁垒是否难抄、收入与成本是否撑得起一门可持续的生意？精益画布是商业支线的"模式基座"，其结论会被 13 NSM、17 GTM、18 优先级引用。

## 怎么分析

### 1. 九模块逐一拆解（每格带编号）

| 模块 | 要回答 | 写法要点 |
|------|--------|---------|
| 问题（Problem） | 用户 Top 3 痛点 | 痛点+严重程度+频次+当前替代方案 |
| 现有替代方案（Existing Alternatives） | 用户现在怎么凑合 | 含"现状/行为惯性"这个隐形最强替代 |
| 解决方案（Solution） | 每个痛点对应什么功能 | 痛点→功能→解决方式一一对应 |
| 独特价值主张（UVP） | 一句话凭什么选你 | 针对最痛的点，有态度 |
| 不公平优势（Unfair Advantage） | 别人抄不抄得走 | 见下方两个判断标准 |
| 客户细分（Customer Segments） | 谁用、谁付、谁决策 | 区分使用方与付费方 |
| 渠道（Channels） | 怎么触达各细分 | 按领域渠道层级列出 |
| 收入来源（Revenue Streams） | 怎么收钱、单价多少 | 计价单位 + 各模式预估单价 |
| 成本结构（Cost Structure） | 固定/可变/人力成本 | 月度运营成本 + 单位经济 |

### 2. "不公平优势"的两个判断标准（必写实）

判断一条优势是否算护城河，必须同时满足：

1. **难复制**：别人没办法轻易抄（领域知识壁垒、技术红线、数据资产、成本结构差异、渠道先发）。
2. **随时间变强**：不是一锤子买卖，越用越深（数据飞轮、网络效应、工作流嵌入、口碑网络）。

只满足一个不算真正的不公平优势。把每条候选优势按"类型 + 可复制难度"列表评估，并说明它在哪个时间阶段成为壁垒。

### 3. 单位经济学（必须算，不能只给收入）

| 指标 | 算法 | 说明 |
|------|------|------|
| CAC | 单渠道获客成本（含激励/物料/差旅/时间） | 分渠道加权 |
| LTV | 年收入/客户 × 平均留存年限 × 毛利率 | 分细分市场算 |
| LTV/CAC | LTV ÷ CAC | 健康底线 ≥ 3:1，标注行业基准来源 |
| Payback | CAC ÷ 月收入 | 越快越好，对比行业健康区间 |
| 边际成本 | 每多一个客户新增的成本（服务/API/支持） | 体现经营杠杆 |

### 4. 三年财务预测 + 敏感性分析

- 自下而上模型：客户数 × 单位数 × 定价。标注口径（与自上而下的市场规模模型可能不同，写明差异）。
- 收入/成本/利润/现金流分年测算。
- **敏感性分析**：对最敏感的 2-3 个变量（续约率、定价、单客渗透率、单位成本）做悲观/基准/乐观三情景，给出收入变动 %。

### 5. 护城河演进 + 验证实验表

- 护城河随时间线演进：种子期（技术/领域壁垒）→ 推广期（数据/渠道壁垒）→ 规模化（网络效应/替换成本）。
- 验证实验表：每个核心假设对应一个实验，含最少成功标准、方法、状态、依赖关系。

## 怎么写（结构）

1. **摘要**：模式一句话 + 最关键的 1 个收入/成本结论。
2. **问题 + 现有替代方案**（3 痛点 + 替代方案表）。
3. **解决方案**（痛点→功能对应表）。
4. **UVP + 不公平优势**（两个判断标准评估）。
5. **客户细分**（使用方/付费方/决策方，标注规模与付费意愿）。
6. **渠道**（按阶段）。
7. **收入来源**（计价单位 + 单价）。
8. **成本结构 + 单位经济**（CAC/LTV/Payback/边际成本）。
9. **三年预测 + 敏感性分析**。
10. **护城河演进 + 验证实验表**。
11. **「所以呢」**：九格里哪格最弱、模式是否成立、先验证哪条收入假设。

## 及格线

- ☑ 九模块都填且有编号，解决方案与问题一一对应。
- ☑ 不公平优势用"难复制 + 随时间变强"两个标准逐条评估，非自夸。
- ☑ 客户细分区分使用方与付费方（含付费方与使用方分离的情形）。
- ☑ 有成本结构与单位经济（CAC/LTV/Payback/边际成本，LTV/CAC 对比行业基准）。
- ☑ 有三年预测 + ≥2 个变量的敏感性分析。
- ☑ 结尾有「所以呢」（模式是否成立、最弱格、先验哪条）。

## 最易挂的坑

- **不公平优势写成"我们有好团队、先发"**：不满足两个判断标准，经不起"对手砸钱能不能抄"的追问。
- **只算收入不算单位经济**：给出"市场很大"就当成立，缺 CAC/LTV/Payback，看不出生意能否自我造血。
- **计价单位错位**：用"学生数"而非"班/校/席位"等客户真正理解的计价单位，导致定价与决策链脱节。
