> 源文档：13-北极星指标.md

## 回答什么问题

用一个**单一指标**衡量"产品到底有没有在创造价值、价值是否在增长"？它要能被团队每个人理解、能驱动行动、能领先于收入。NSM 是商业支线的"仪表盘指针"，被 14 OST 作为期望成果、18 功能优先级作为 Impact 标尺。

## 怎么分析

### 1. 商业游戏分类（先定调）

先判断产品属于哪类"游戏"，决定 NSM 的方向：

- **生产力游戏（Productivity）**：用户为完成某项任务而来 → NSM 衡量"完成了多少核心任务"。
- **注意力游戏（Attention）**：用户停留时长即价值 → NSM 衡量"花了多少时间/打开次数"。
- **交易游戏（Transaction）**：用户间发生交易 → NSM 衡量"交易笔数/金额"。

判断依据：核心价值交付是什么、用户为什么来、与同类产品的区别。

### 2. 候选 NSM 与 7 标准验证（核心）

列出 3-5 个候选指标，逐个用 7 标准验证，选 1 个主指标：

| 标准 | 含义 |
|------|------|
| 1. 易于理解 | 任何人都能秒懂 |
| 2. 客户中心 | 每涨一点都代表用户获得了价值 |
| 3. 可持续价值 | 使用越久价值越深（飞轮） |
| 4. 愿景对齐 | 与产品愿景一致 |
| 5. 可量化 | 数据库可直接精确计数 |
| 6. 可行动 | 任何角色都能找到自己如何影响它 |
| 7. 先行指标 | 领先于留存/收入约 3-6 个月 |

每个候选写清"为什么推荐/为什么不推荐"（如规模指标≠价值指标、下游行为≠源头行为、难测量≠好指标）。

### 3. 指标定义与边界条件

- 给出 NSM 的精确定义、计数规则、不计数的情况、数据来源（表/字段）、报告频率。
- **边界条件**：写清哪些情况会误导 NSM，以及规避方式（如刷量混淆、低质量计数、单点依赖），用辅助/反指标监控。

### 4. 阶段目标基准与季节性

- 按阶段（种子/推广/规模/成熟）给 NSM 基准，写明计算依据（客户数×单位数×频次×转化率×覆盖率）。
- **季节性**：列出业务淡旺季对 NSM 的影响，决定用"同比（YoY）"还是"环比（MoM）"评估。

### 5. 输入指标星座（Metrics Constellation）

NSM = f(若干输入指标)。列出 3-5 个输入指标（广度/质量/规模/完整性/速度），每个给定义、为什么重要、如何提升、目标、拆解维度。用图展示 NSM 与输入指标的关系。

### 6. 与 NSM 的相关性/敏感性分析

- 理论模型：NSM = 输入指标乘积/函数。
- 敏感性：评估每个输入的边际改善对 NSM 的贡献、难度、优先级。
- 场景模拟：乐观/保守两条路径的 NSM 推演。

### 7. 反指标（健康指标 / Counter-Metrics）

NSM 涨了不代表健康，反指标防止"用错误方式让指标变好"：列出反指标、黄色/红色警报线、说明。含严重事故级反指标（如安全事故、隐私泄露）的即时响应。

### 8. 可比基准 / 仪表盘 / 审查节奏 / 与 OKR 关系 / 生命周期审查

- 可比基准：同类产品的 NSM 与行业经验值。
- 仪表盘：核心/趋势/输入/反指标/分解视图 + 预警颜色。
- 审查节奏：日/周/月/季/年分别看什么、做什么决策。
- 与 OKR：NSM 是"长期价值度量"，OKR 是"短期聚焦"，每季 OKR 要能解释对 NSM 的贡献。
- 生命周期审查：产品/商业模式/用户行为发生重大变化时，何时重新审视 NSM 定义。

## 怎么写（结构）

1. **摘要**：选了哪个 NSM、一句话理由。
2. **商业游戏分类**。
3. **候选 NSM + 7 标准验证表**（选 1）。
4. **NSM 精确定义 + 边界条件**。
5. **阶段基准 + 季节性**。
6. **输入指标星座**（3-5 个）。
7. **相关性/敏感性 + 场景模拟**。
8. **反指标清单**。
9. **可比基准 + 仪表盘 + 审查节奏**。
10. **与 OKR 关系 + 生命周期审查**。
11. **「所以呢」**：NSM 为何是这个、团队下季怎么围绕它行动。

## 及格线

- ☑ 先定商业游戏分类，再选 NSM。
- ☑ 给出≥3 个候选，用 7 标准验证并明确选 1 个、弃其余的理由。
- ☑ NSM 有精确定义、计数规则、数据来源、报告频率、边界条件。
- ☑ 有输入指标星座（≥3 个）+ 反指标（≥3 个，含红色警报线）。
- ☑ 有阶段基准（带计算依据）+ 季节性处理（YoY/MoM 选择）。
- ☑ 有审查节奏 + 与 OKR 关系 + 生命周期审查触发条件。
- ☑ 结尾有「所以呢」。

## 最易挂的坑

- **选成规模指标当 NSM**：周活/注册数只衡量"来了多少人"，不衡量"创造了什么价值"，会误导团队做拉新而非做价值。
- **NSM 不可行动**：选了"客户节省的总时间"这类难精确测量的指标，团队无法找到自己如何影响它。
- **只报 NSM 不报反指标**：指标涨了就庆祝，没发现是"低质量计数/刷量/单点依赖"堆出来的虚高。
