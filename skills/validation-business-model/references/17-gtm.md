> 源文档：17-GTM策略.md

## 回答什么问题

产品验证了价值，怎么把它卖出去、收回来、并持续增长？GTM 回答市场选择（打哪块）、模式选择（B2B/B2C/B2B2C）、竞品打法、定价、渠道 ROI、执行日历、合作伙伴、上线清单、KPI 与扩张路线图。它是商业支线的"打法"，其节奏决定 18 功能优先级先服务哪类用户。

## 怎么分析

### 1. GTM 概览与模式选择依据

- 概览表：目标市场 / 滩头细分 / 运动类型（自上而下 or 自下而上）/ 增长引擎 / 差异化 / 当前阶段 / 成本基线。
- **模式选择**：对比 B2B（学校/企业采购）、B2C（个人付费）、B2B2C（机构付费基础 + 终端增值）三者的付费方、获客成本、决策周期、ARPU、使用驱动力、续费驱动力，给出选型结论与"为什么"（付费方与使用方分离时的组合打法）。

### 2. 市场选择逻辑

- 滩头市场依据：为何先打这块（竞争强度、种子基础、地域/行业壁垒、扩张路径、成本）。
- TAM/SAM/SOM：分层量化，标注计算逻辑。

### 3. 竞品战报（Battlecards）

- 竞品全景矩阵：类型 / 覆盖 / 核心功能 / 主要客户 / 收入估 / 你的领域深度。
- 逐一对主要竞品写：定位 / 核心优势 / 局限（尤其在你专注领域的薄弱点）/ 定价 / 销售模式 / **攻击策略（不对称竞争话术）/ 防御策略**。含"现状/行为惯性"这一隐形最强竞品。
- 竞争优势总结表：各维度 vs 各竞品（领先/持平/落后），收口到你的核心壁垒。

### 4. 定价哲学与方案

- **定价哲学**：如"轻决策（让关键决策者能拍板的价格）""按领域计价单位（如按班/按席位而非按人）""阶梯渗透（先免费占场景再提价）"。
- 方案详情：基础/标准/专业等分层 + C 端增值 + B2G 大客户，各给单价、包含功能、目标客户、占比。
- **竞品定价对比** + **价格弹性**（各价格点接受率）+ **价格锚定**（对比竞品/对比用户现有成本/对比替代方案，而非成本加成）。

### 5. 渠道策略与各渠道 ROI 模型

- 渠道全景：类型 × 各阶段权重 × CAC × 转化周期。
- 每个核心渠道给 ROI 模型：触达数 / 线索转化率 / 试用转化率 / 付费转化率 / 单校 CAC / LTV/CAC / 年度 ROI。
- 渠道组合时间线（种子/推广/规模期权重变化）。

### 6. 12 个月执行日历

- 逐月：主题 / 关键里程碑 / 销售市场动作 / 产品技术动作 / 衡量指标。
- 前 90 天细化到 30 天行动块。

### 7. 分层信息策略（Messaging）

- 分受众（决策者 / 核心使用者 / 终端用户/家长）各给：一句话定位 / 核心论点 / 信任建设 / ROI 论证 / 避免强调。
- 阶段性信息演进（种子期共创 → 推广期社交证明 → 规模期数据驱动）。

### 8. 合作伙伴策略 + 上线日检查清单 + KPI + 风险评估 + 扩张路线图

- 合作伙伴分层（战略/渠道/生态/辅助）+ 推进路线图 + 选择标准（是否触达新用户、是否增强专注度、对接成本、战略一致）。
- 上线日检查清单（上线前1周/当天/后1周；新客户 onboarding 步骤）。
- KPI 体系（获客/激活/使用/质量/满意度/留存/收入/传播，分三阶段目标）。
- 风险评估与缓解（风险×可能性×影响×缓解×监测信号）。
- 滩头扩张路线图（Phase 1→N 的触发条件 + 新区域就绪度检查 + 跨省/跨域攻略）。

## 怎么写（结构）

1. **摘要**：GTM 一句话 + 最关键的 1 个模式/市场结论。
2. **GTM 概览 + 模式选择依据**。
3. **市场选择逻辑 + TAM/SAM/SOM**。
4. **竞品 Battlecards + 优势总结**。
5. **定价哲学 + 方案 + 弹性 + 锚定**。
6. **渠道策略 + 各渠道 ROI 模型 + 组合时间线**。
7. **12 个月执行日历**。
8. **分层 Messaging**。
9. **合作伙伴策略**。
10. **上线检查清单 + KPI + 风险评估 + 扩张路线图**。
11. **「所以呢」**：先打哪块市场、主渠道、定价锚、第一年最该盯的 KPI。

## 及格线

- ☑ 市场选择有依据（含 B2B/B2C/B2B2C 模式选择理由，说明付费方与使用方关系）。
- ☑ 有竞品 Battlecards（定位/优势/局限/攻击与防御策略），含"现状/行为惯性"竞品。
- ☑ 定价有哲学（轻决策/计价单位/阶梯渗透）+ 分层方案 + 弹性表 + 锚定策略。
- ☑ 各核心渠道有 ROI 模型（触达→线索→试用→付费→CAC→LTV/CAC）。
- ☑ 有 12 个月执行日历（含前 90 天细化）+ 上线检查清单 + KPI 体系（分三阶段）。
- ☑ 有风险评估（可能性×影响×监测信号）+ 扩张路线图（触发条件）。
- ☑ 结尾有「所以呢」。

## 最易挂的坑

- **定价用成本加成**：不看用户现有成本/竞品价做锚定，定价脱离付费方决策心理。
- **渠道只列不建模**：写出一堆渠道却没 ROI 模型，无法决定资源往哪投。
- **忽略"现状/行为惯性"竞品**：只盯付费竞品，漏掉"用户现在用 Excel/手工凑合"这个最强替代，导致 GTM 打错对象。
